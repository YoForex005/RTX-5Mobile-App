# RTX5 Documentation Guide Pack

This folder is the permanent project guide for RTX5 frontend delivery. It is designed so any engineer can resume work without losing decisions or context.

## Quick Start (under 5 minutes)
1. Read [MASTER_GUIDE.md](./MASTER_GUIDE.md) for roadmap and ownership.
2. Confirm architecture constraints in [ARCHITECTURE.md](./ARCHITECTURE.md).
3. Validate integration contracts in [API_CONTRACTS.md](./API_CONTRACTS.md).
4. Open the active phase file from the phase index below.
5. Use [UI_PARITY_SCREEN_MAP.md](./UI_PARITY_SCREEN_MAP.md) to map screenshot parity requirements.

## Project Defaults Locked In
- Frontend only. Existing backend is out of scope.
- React Native with Expo Dev Client.
- TanStack Query + Zustand.
- React Hook Form + Zod.
- Custom React Native Skia chart engine.
- No third-party logo inside chart UI.
- OTA via EAS Update using staged channels.
